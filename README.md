# Жасанды интеллект технологияларын қолдану арқылы автокөліктерді қысқа мерзімді жалға алу және броньдау мобильді қосымшасы

Бұл мобильді қосымша автокөлікті қысқа мерзімге тез іздеу, броньдау және төлеу мәселесін шешеді. Жасанды интеллект пайдаланушының қалауына сай автокөлік ұсынады. Қосымша жүргізушілерге және жалға беру қызметінің қызметкерлеріне арналған.

## Мақсаты
Жасанды интеллект көмегімен автокөлікті қысқа мерзімге жалға алу және броньдау процесін жылдам әрі ыңғайлы ету.

## Пайдаланушылар
- Клиент (жалға алушы)
- Менеджер
- Әкімші

## Талаптар
1. Клиент жүйеге тіркеліп, жүргізуші куәлігінің деректерін енгізеді.
2. Клиент орны мен уақытын көрсетіп, бос автокөліктерді іздейді.
3. Жүйе жасанды интеллект арқылы клиентке сәйкес автокөліктерді ұсынады.
4. Клиент таңдаған автокөлігін белгілі уақытқа броньдайды.
5. Клиент жалға алу ақысын қосымша арқылы төлейді.
6. Жүйе клиентке броньдау нәтижесі туралы хабарлама жібереді.
7. Менеджер клиенттің жүргізуші куәлігін тексеріп, растайды.
8. Әкімші автокөліктерді қосады, өзгертеді және өшіреді.
